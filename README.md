# Ozon → Telegram

Личный бот для отправления **0105952439-0043-1**. Проверяет Ozon каждые 15 минут,
присылает начальный статус, затем изменения состоявшихся событий и срока доставки.
Будущие этапы без даты не считаются выполненными. Состояние хранится в SQLite:
перезапуск не вызывает повторного уведомления. Ошибки Ozon не заменяют статус.

## Запуск

Python 3.11+:

```sh
cd /home/lemetist/ozon-tracking-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium
cp .env.example .env
chmod 600 .env
```

Создайте бота через https://t.me/BotFather командой `/newbot`.
Вставьте токен в `TELEGRAM_BOT_TOKEN` в `.env`. Токен не публикуйте.
Можно указать свой числовой `TELEGRAM_CHAT_ID`; иначе владельцем станет первый,
кто напишет боту `/start` в личку. Остальные не получат доступ к отправлению.

```sh
.venv/bin/python bot.py
```

Откройте своего бота и отправьте `/start`. `/status` показывает сохранённый
результат и время проверки, `/check` запускает проверку (не чаще раза в минуту),
`/stop` отключает отслеживание. `/start` включает его снова.
Для уведомлений процесс должен постоянно работать, а компьютер — оставаться включённым.
Не запускайте два экземпляра с одним токеном. Если у бота раньше был webhook,
его нужно предварительно отключить; программа сама его не удаляет.

Для работы в фоне после заполнения `.env` можно установить пользовательский сервис:

```sh
mkdir -p ~/.config/systemd/user
cp ozon-tracking-bot.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ozon-tracking-bot
journalctl --user -u ozon-tracking-bot -f
```

Сервис работает в рамках пользовательской сессии; для работы после выхода
из неё потребуется включённый linger (`loginctl enable-linger "$USER"`).

## Проверка Ozon без токена

```sh
.venv/bin/python bot.py --once
```

Страница и её JSON-запрос открываются через Chromium; профиль сохраняется в
`data/browser`. Если Ozon требует ручной проверки, на компьютере с графическим
окружением выполните:

```sh
.venv/bin/python bot.py --login
```

Пройдите проверку в открывшемся окне в течение двух минут. Затем запустите бота
обычным способом с тем же каталогом `data`. Антибот может повторно ограничить
доступ; гарантировать его прохождение нельзя. При изменении формата API бот
сохранит последний успешный статус; после трёх неудачных проверок сообщит о проблеме.

Можно использовать установленный браузер, указав `CHROMIUM_EXECUTABLE` в `.env`.
В таком случае `playwright install chromium` не требуется. При недостающих
системных библиотеках используйте `playwright install --with-deps chromium`.

Проверки логики: `.venv/bin/python -m unittest -v`.

Документация: https://core.telegram.org/bots/api,
https://playwright.dev/python/docs/browsers.
